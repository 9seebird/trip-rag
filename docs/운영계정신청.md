# 공공데이터포털 운영계정 신청 준비

대상 API: **한국관광공사_국문 관광정보 서비스_GW** (KorService2)

개발계정은 하루 1,000회. 포털 이용가이드 기준으로 운영계정은 하루 최대 10만 건까지 가능하다.
실제로 몇 회를 받을지는 제공기관(한국관광공사) 승인에 달려 있다.
전국 33,486곳을 받으려면 상세·소개정보만 약 67,000회라, 운영계정이면 하루 이틀이면 끝난다.

## 절차

1. 서비스 배포 (`docs/배포가이드.md`) → 주소와 화면이 실제로 떠 있어야 한다
2. 공공데이터포털 → 마이페이지 → 오픈API → 개발계정 → 해당 API → **운영계정 신청**
3. 활용사례 등록 (아래 문구) + 화면 캡처 첨부
4. 승인되면 `.env` 의 `TOUR_DAILY_LIMIT` 과 `scripts/daily_collect.ps1` 의 `TOUR_DAILY_LIMIT=950` 을 올린다

화면 이름·항목은 포털 개편으로 바뀔 수 있으니 신청할 때 화면을 보고 맞춰 넣는다.

## 활용사례 문구 (붙여넣기용)

**서비스명**  반나절 — 말로 찾는 여행 코스

**서비스 주소**  https://trip.trendkit.app

**서비스 유형**  웹 서비스 (비영리, 개인 포트폴리오)

**한 줄 소개**
상황을 말로 적으면 관광지·음식점을 찾고, 고른 곳 근처로 반나절 코스를 짜 주는 여행 검색 서비스

**서비스 설명**
“비 오는 날 아이랑 갈 만한 실내”, “바다 보면서 커피 마실 곳”처럼 여행자가 처한 상황을 문장으로 입력하면,
한국관광공사 관광정보의 소개글을 의미 기반으로 검색해 알맞은 장소를 보여줍니다.
실내/실외, 지역, 장소 유형 같은 조건은 질문에서 뽑아 먼저 걸러내고,
운영시간·휴무일·주차·유모차 정보는 소개정보에서 가져와 함께 표시합니다.
장소를 하나 고르면 반경 안의 볼거리·식당·카페를 골라 이동 거리와 시간을 계산한 반나절 코스를 지도와 함께 제공합니다.
현재 제주·부산·강원 지역을 제공하며, 전국으로 넓혀 갈 예정입니다.

**활용 데이터와 방법**
- 지역기반 관광정보(areaBasedList2): 지역별 관광지·문화시설·레포츠·축제·음식점 목록과 좌표
- 공통정보(detailCommon2): 장소 소개글 — 의미 검색의 색인 재료
- 소개정보(detailIntro2): 운영시간·휴무일·주차·요금·유모차 — 조건 표시
- 수집한 데이터는 자체 DB 에 저장해 검색에 쓰며, 이용자 요청마다 API 를 다시 부르지 않습니다(호출량 절약)

**운영계정이 필요한 이유**
전국 약 3만 3천 곳의 공통정보·소개정보를 받으려면 약 6만 7천 회 호출이 필요합니다.
개발계정(하루 1,000회)으로는 두 달 넘게 걸려 전국 서비스를 제공하기 어렵고,
관광정보가 바뀐 곳을 주기적으로 다시 받아 최신 상태를 유지하는 데도 추가 호출이 필요합니다.

**출처 표시**
모든 화면 하단에 “관광정보 출처: 한국관광공사 (TourAPI · 공공데이터포털)”와 사진 저작권 안내를 표시합니다.

## 첨부할 화면 캡처

1. 첫 화면 (검색창 + 지역 탭)
2. 검색 결과 (카드 + 지도)
3. 반나절 코스 (동선 + 지도)
4. 화면 하단 출처 표시가 보이게 한 장
