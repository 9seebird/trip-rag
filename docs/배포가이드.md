# 배포 가이드 — trip.trendkit.app

목표: 공공데이터포털 **운영계정 신청**에 쓸 "실제로 접속되는 서비스 주소와 화면"을 만든다.

```
집 PC (수집·색인)                         Azure 서버 (서비스)
 작업 스케줄러 → TourAPI 수집             nginx (443) ── trip.trendkit.app
 enrich · build_index (모델 비용)            └→ api 컨테이너 127.0.0.1:8090
 dump_db.ps1 ──── .dump 파일 ── scp ──→     └→ db 컨테이너 (포트 안 엶)
```

서버는 TourAPI 를 부르지 않는다. 수집·색인은 집 PC 에서 하고 DB 를 통째로 옮긴다.
(같은 키를 두 곳에서 쓰면 하루 한도를 나눠 쓰게 되고, 해외 리전 서버는 공공 API 가 막힐 수도 있다.)

---

## 0. 집 PC — 부산 데이터를 검색에 넣기

부산은 수집만 돼 있고 **실내/실외 판정(enrich)과 색인(build_index)이 아직 안 돼 있다.**
색인이 안 된 곳은 검색에 안 나온다 (화면의 지역 탭에도 안 뜬다).

```powershell
docker compose --profile tools run --rm ingest python -m ingest.enrich
docker compose --profile tools run --rm ingest python -m ingest.build_index
docker compose up -d api        # http://localhost:8080  새 화면,  /lab  비교 화면
```

강원은 수집이 끝난 뒤 같은 두 줄을 다시 돌리면 된다 (이미 한 곳은 건너뛴다).

## 1. DNS

trendkit.app 도메인 관리 화면에서 **A 레코드** `trip` → Azure 서버 공인 IP.

## 2. 서버 — 코드와 .env

```bash
git clone https://github.com/9seebird/trip-rag.git ~/trip-rag
cd ~/trip-rag
cp .env.example .env
nano .env
```

`.env` 에서 바꿀 것

| 키 | 값 |
|---|---|
| `BIZROUTER_API_KEY` | 집 PC 와 같은 키 (검색·코스에 필요) |
| `TOUR_API_KEY` | 비워도 된다 (서버는 수집 안 함) |
| `POSTGRES_PASSWORD` | 새로 길게 |
| `KAKAO_JS_KEY` | 아래 5번 |
| `API_PORT` | `8090` (다른 서비스와 겹치면 바꾸고 nginx 설정도 같이) |
| `RATE_PER_MIN` / `DAILY_REQUEST_LIMIT` | 기본 12 / 1500. 하루 비용 상한이 된다 |

```bash
docker compose -f docker-compose.prod.yml up -d --build
```

## 3. DB 옮기기

집 PC:
```powershell
powershell -ExecutionPolicy Bypass -File scripts\dump_db.ps1
scp triprag_YYYYMMDD.dump <사용자>@<서버>:~/trip-rag/
```

서버:
```bash
docker cp triprag_YYYYMMDD.dump triprag-prod-db:/tmp/t.dump
docker exec triprag-prod-db pg_restore -U triprag -d triprag --clean --if-exists --no-owner /tmp/t.dump
docker exec triprag-prod-db rm /tmp/t.dump
curl -s localhost:8090/api/config      # regions 에 제주·부산이 나오면 성공
```

데이터를 갱신할 때(강원 추가 등)도 3번만 다시 하면 된다.

## 4. nginx + HTTPS

```bash
sudo cp deploy/trip.trendkit.app.conf /etc/nginx/sites-available/
sudo ln -s /etc/nginx/sites-available/trip.trendkit.app.conf /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d trip.trendkit.app
```

nginx 가 컨테이너로 돌고 있으면 위 설정의 `127.0.0.1:8090` 을 그 환경에 맞게 바꾼다
(portal.trendkit.app 을 붙인 방식과 똑같이).

## 5. 카카오 지도 키

1. developers.kakao.com → 내 애플리케이션 → 애플리케이션 추가 (이름 예: 반나절)
2. 앱 키 → **JavaScript 키** 복사 → 서버 `.env` 의 `KAKAO_JS_KEY`
3. 플랫폼 → Web → 사이트 도메인에 `https://trip.trendkit.app` (로컬 확인용 `http://localhost:8080` 도)
4. 카카오맵 사용 설정이 따로 있으면 켠다
5. `docker compose -f docker-compose.prod.yml up -d` (env 다시 읽기)

키가 없으면 지도 칸 없이 목록만 나온다. 서비스는 그대로 돈다.
