# 배포 가이드 — 집 노트북(Ubuntu) + Cloudflare Tunnel

Azure 서버가 내려가서 집 노트북으로 옮긴다. 주소는 운영계정 신청서와 같은 `trip.trendkit.app`.

```
맥북 (코드 수정)                          노트북 Ubuntu (서비스 + 매일 수집)
 고치고 커밋 → git push ──→ GitHub ──→     git pull
                                            api 컨테이너 ── tunnel 컨테이너 ──→ Cloudflare ──→ trip.trendkit.app
                                             └→ db 컨테이너 ←─ ingest 컨테이너 (cron 매일 10:00 KST)
                                                                TourAPI 수집 → 실내/실외 판정 → Gemini 색인
```

수집도 서버에서 한다. 서비스 DB 에 바로 쌓이므로 DB 덤프를 옮길 일이 없다 (2장은 처음 한 번만).

공유기 포트포워딩·nginx·인증서가 필요 없다. 터널이 밖으로 나가는 연결만 쓰고, https 는 Cloudflare 가 붙인다.

## 0. 준비 (한 번만)

1. **trendkit.app DNS 를 Cloudflare 로** — Cloudflare 에 사이트 추가 → 알려주는 네임서버 2개를
   도메인 구입처(네임칩 등) 네임서버 설정에 넣는다. 반영까지 몇 분~몇 시간.
   (Vercel 등에 붙어 있던 기존 레코드는 Cloudflare 가 가져오는지 확인)
2. **터널 만들기** — Cloudflare Zero Trust → Networks → Tunnels → Create a tunnel (Cloudflared)
   → 이름 `triprag` → 설치 화면의 명령에 들어 있는 **토큰**(긴 문자열)만 복사.
3. **Public Hostname** — 같은 터널 설정에서 `trip` . `trendkit.app` → Service `HTTP` · `api:8000`

## 1. 노트북

```bash
# Docker 가 없으면
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER      # 로그아웃 후 다시 로그인

git clone https://github.com/9seebird/trip-rag.git ~/trip-rag
cd ~/trip-rag
nano .env          # Windows PC 의 .env 를 옮기고 아래만 확인
```

| 키 | 값 |
|---|---|
| `LLM_PROVIDER` | `gemini` |
| `GEMINI_API_KEY` | Windows PC 와 같은 키 |
| `POSTGRES_PASSWORD` | 새로 길게 (노트북 DB 는 새로 만들어지므로 아무 값) |
| `TUNNEL_TOKEN` | 0-2 에서 복사한 토큰 |
| `KAKAO_JS_KEY` | 그대로 (카카오에 `https://trip.trendkit.app` 이미 등록됨) |

```bash
docker compose -f docker-compose.prod.yml --profile tunnel up -d --build
```

## 2. DB 옮기기

Windows PC (PowerShell):
```powershell
powershell -ExecutionPolicy Bypass -File scripts\dump_db.ps1
scp triprag_YYYYMMDD.dump 사용자@노트북IP:~/trip-rag/
```

노트북:
```bash
cd ~/trip-rag
docker cp triprag_YYYYMMDD.dump triprag-prod-db:/tmp/t.dump
docker exec triprag-prod-db pg_restore -U triprag -d triprag --clean --if-exists --no-owner /tmp/t.dump
curl -s localhost:8080/api/config      # .env 의 API_PORT. regions 에 제주·부산·강원
```

## 3. 꺼지지 않게

운영계정 심사 중에 서버가 죽으면 반려된다 (실제로 한 번 반려됨).

```bash
# 덮개를 닫아도 잠들지 않게
sudo sed -i 's/^#\?HandleLidSwitch=.*/HandleLidSwitch=ignore/; s/^#\?HandleLidSwitchExternalPower=.*/HandleLidSwitchExternalPower=ignore/' /etc/systemd/logind.conf
sudo systemctl restart systemd-logind
# 절전 끄기
sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target
# 재부팅해도 Docker 가 뜨게 (컨테이너는 restart: unless-stopped 라 같이 뜬다)
sudo systemctl enable docker
```

## 5. 매일 수집 (cron)

수집·판정·색인을 서버가 매일 한 번 돌린다. 새 장소가 다음 날 바로 검색에 나온다.

| 파일 | 역할 |
|---|---|
| `scripts/areas.txt` | 수집할 지역 코드. 지역을 늘리고 줄일 때는 이 파일만 고치면 된다 (cron 재등록 불필요) |
| `scripts/daily_collect.sh` | `ingest.daily` → `ingest.enrich` → `ingest.build_index`. 로그 `logs/collect_YYYYMMDD.log` |
| `scripts/install_cron.sh` | cron 등록. 서버 시간대가 UTC 여도 한국 시각 10:00 으로 환산해서 넣는다 |
| `docker-compose.prod.yml` 의 `ingest` | `profiles: ["tools"]` 라 평소엔 안 뜬다. 코드는 마운트라 `git pull` 만 하면 다음 수집부터 반영 |

```bash
cd ~/server/trip-rag          # 노트북의 저장소 위치
git pull
docker compose -f docker-compose.prod.yml --profile tunnel up -d --build   # api 도 새 지역 이름으로
docker compose -f docker-compose.prod.yml build ingest                       # 처음 한 번 (수집기 이미지)

bash scripts/daily_collect.sh      # 손으로 한 번 돌려 보기 — 한도 950회를 다 쓰니 날을 골라서
tail -n 60 logs/collect_$(TZ=Asia/Seoul date +%Y%m%d).log

bash scripts/install_cron.sh       # 매일 10:00 (한국 시각) 등록
crontab -l                         # 확인
```

* 시각 바꾸기 `bash scripts/install_cron.sh 13:10` · 해제 `bash scripts/install_cron.sh --remove`
* cron 이 docker 를 부르려면 이 계정이 `docker` 그룹이어야 한다 (`groups` 로 확인).
* 운영계정 승인 후 한도 올리기: crontab 줄 앞에 `TOUR_LIMIT=승인된한도-50 ` 을 붙이거나 스크립트의 `950` 을 바꾼다.
  `.env` 의 `TOUR_DAILY_LIMIT` 도 같이 (손으로 돌릴 때 기준).
* **다른 PC 의 작업 스케줄러는 끈다.** 같은 TourAPI 키 한도를 나눠 쓰게 된다.
  Windows PowerShell: `Unregister-ScheduledTask -TaskName "trip-rag 수집" -Confirm:$false`
* 같은 날 두 번 돌려도 안전하다 — 한도를 다 쓴 날은 TourAPI 호출 0회로 지나가고, 판정·색인만 남은 것을 한다.
  겹쳐 돌면 뒤에 시작한 쪽이 건너뛴다 (`flock`).
* 노트북이 10시에 꺼져 있었으면 그날은 건너뛴다 (다음 날 이어서 받으므로 하루 늦어질 뿐).
